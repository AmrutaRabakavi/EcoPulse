# EcoPulse Smart Contracts (Proof of Green Deed)

This directory contains Solidity smart contracts for non-transferable (Soulbound) green deed credentials.

## Architecture
- **Standard**: ERC-721 Soulbound Token (SBT) / Non-transferable verifiable badge.
- **Network**: Polygon Amoy Testnet / Ethereum Sepolia.
- **Trigger**: Minted when students achieve eco-milestones (e.g. 500 eco-points or verified campus deeds).
- **MVP Status**: Mocked cryptographically generated deed transaction hashes in MVP, deployed to testnet in Phase 8.
